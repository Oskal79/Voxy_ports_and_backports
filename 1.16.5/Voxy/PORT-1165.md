## 2. Key Architecture Differences (1.21.1 vs 1.16.5)

| Feature | Modern (1.21.1 / NeoForge) | Legacy (1.16.5 / Forge) |
|---|---|---|
| **Lighting Delivery** | Bundled in chunk data or updated atomically before Sodium `onChunkAdded` | Separate `SChunkDataPacket` and `SUpdateLightPacket`. `SectionLightStorage` has `visibleSectionData` (read) and `queuedSections` (pending from network) |
| **Empty `NibbleArray`** | Null or present | `new NibbleArray()` has `data == null`, `isEmpty() == true`, `get(...) == 0` |
| **Open Sky Above Terrain** | Stored or queried via level height | `SkyLightStorage` sends NO arrays above terrain; reads 15 once above `topSection` |
| **Biomes** | Per-section (4x4x4 quart local) in `PalettedContainer` | Per-column in `BiomeContainer`, indexed by `(sectionY << 2) + y` |
| **Terrain Renderer** | Sodium `DefaultChunkRenderer.render(...)` with matrices | `SodiumWorldRenderer.drawChunkLayer` (projection read from GL11) |
| **Visibility Culling** | Sodium `ChunkTracker` | Embeddium `ChunkRenderManager.addChunkToRenderLists` with `chunk.getFacesWithData() != 0` |

## 3. Resolved Issues & Root Causes

### 1. Black/Orange Artifacts on Vanilla Chunks
- **Root Cause**: Concurrency desync between main thread palette resizing and Voxy worker threads reading `PalettedContainer`.
- **Fix**: Implemented `SectionSnapshot` to atomically capture palette and packed storage on the owning thread before dispatching to workers.

### 2. Holes Around Player
- **Root Cause**: `MixinChunkRenderManager` previously hooked `addChunk` before culling or mesh building, marking chunks as rendered even when Embeddium hadn't built them yet or fog culled them.
- **Fix**: Hooked `addChunkToRenderLists` gated on `chunk.getFacesWithData() != 0` and non-empty data.

### 3. Fake Black Outer Walls on Boundaries
- **Root Cause**: `acquireNeighborData` called `world.acquire(...)`, creating empty 0-filled sections for non-existent neighbors, which the mesher interpreted as air with light 0.
- **Fix**: Changed to `this.world.acquireIfExists(...)`, tracking existing neighbors in `presentNeighbors` bitmask and skipping outer geometry facing missing neighbors.

### 4. 1-Chunk Black Border & Black Flickering on Movement
- **Root Cause**:
  1. `replaceWithPacketData` creates empty `NibbleArray`s (`isEmpty() == true`) before light packet arrives.
  2. `enqueueIngest` checked `getDataLayerData(pos) != null`, which accepted empty arrays as valid lighting, storing `sky = 0` for terrain.
  3. `DeferredRelightIngest` delayed light ingestion by 150 ms upon receiving `SUpdateLightPacket`.
- **Fix**:
  1. `enqueueIngest` strictly checks `!data.isEmpty()` for `topSkySection`. Chunks without light packets are rejected (`return false`) and never overwritten with 0.
  2. `MixinClientPacketListenerLight` immediately calls `tryAutoIngestChunk(chunk)` at `@At("TAIL")` of `handleLightUpdatePacked`, utilizing `queuedSections` synchronously without delay.
  3. `getLightingSupplier` differentiates `fallback`: `15` for sections at or above `topNonNullSection`, `0` for underground.
